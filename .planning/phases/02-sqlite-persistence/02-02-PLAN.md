    - Constructor: WriteBufferQueue({required this.onFlush, this.debounceDuration = const Duration(milliseconds: 200), this.batchSize = 10, this.highWaterMark = 20}).
    - void enqueue(NetworkRecord record):
      Two-phase in-memory coalescing (per D-22): Store record in _buffer[record.id] = record. If a pending record with this ID is already queued in RAM when the response or error arrives, it is updated in-place, combining request and response fields into a single completed record before any disk I/O.
      High-water mark check (per D-23): If _buffer.length >= highWaterMark, immediately cancel _debounceTimer and invoke _triggerFlush() asynchronously to drain the burst.
      Otherwise: Cancel active _debounceTimer and schedule _triggerFlush() after debounceDuration (200ms, per D-21).
    - Future&lt;void&gt; flush():
      Cancel _debounceTimer and immediately invoke _triggerFlush() to guarantee all queued items are persisted (per D-24).
    - Future&lt;void&gt; _triggerFlush():
      Guard against concurrent flush (_isFlushing || _buffer.isEmpty). Set _isFlushing = true.
      Extract itemsToFlush = _buffer.values.toList() and clear _buffer.
      Wrap onFlush(itemsToFlush) in try-catch for defensive error isolation.
      In finally, set _isFlushing = false; if _buffer.isNotEmpty, reschedule _debounceTimer.
    - void dispose():
      Cancel _debounceTimer, clear _buffer, and release references (per D-24).
