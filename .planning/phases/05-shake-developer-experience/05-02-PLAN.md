<objective>
Implement the root application integration wrapper and enhanced programmatic invocation APIs. Build `NetworkInspectorWrapper` to attach device shake detection and lifecycle observation with zero configuration boilerplate. Enhance `NetworkInspector.open([BuildContext? context])` to support contextless programmatic opening via `navigatorKey`. Ensure route stacking prevention via `NetworkInspector.isOpen` and complete release-mode no-op guarantees. Expose wrapper and detector in public barrel exports.

Purpose: Allow developers to integrate the inspector into any Flutter app with a single root wrapper or programmatic call without manual lifecycle plumbing or route stacking.
Output: `NetworkInspectorWrapper` widget, updated `NetworkInspector` facade, public exports, and comprehensive widget test suite.
</objective>
