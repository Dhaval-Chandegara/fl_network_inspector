<objective>
Implement terminal-executable cURL command generation and native platform share sheet export. Build `CurlGenerator` to parse `NetworkRecord` into multi-line bash-escaped CLI commands with line continuations (`\`), `-X METHOD`, `-H 'header: value'`, and safely quoted `--data-raw '...'`. Build `ShareExporter` wrapping `share_plus: ^13.3.1` with safe iPadOS/macOS `RenderBox` anchor origin calculation (`sharePositionOrigin`) to eliminate fatal `NSGenericException` popover crashes. Add a multi-format export sheet (Markdown, cURL, JSON) with sensitive header exclusion. Wire export actions into `NetworkInspectorDetailScreen` and expose screens in `lib/flutter_network_inspector.dart`.

Purpose: Enable developers to copy terminal-reproducible cURL commands and export complete diagnostic reports via native OS sharing sheets without crashing iPadOS/desktop or leaking private headers.
Output: cURL generator utility, safe share sheet exporter, multi-format export action sheet, detail screen export wiring, public barrel exports, and automated test suites.
</objective>

  <action>
    Implement terminal-executable cURL command formatting:
    1. Create `lib/src/ui/utils/curl_generator.dart` implementing `CurlGenerator` per UI-10 and D-61:
       - Declare `const CurlGenerator._();`.
       - Method `static String fromRecord(NetworkRecord record)`:
         - Construct multi-line buffer starting with `curl -X ${record.method.toUpperCase()} \\\n  '${_escapeBash(record.url)}'`.
         - Iterate `record.requestHeaders.entries`: omit pseudo-headers starting with `:` or internal tracking headers (`x-fl-net-inspector-tracked-id`); escape key and value; append ` \\\n  -H '${_escapeBash(key)}: ${_escapeBash(value)}'`.
         - If `record.requestBody?.body` is non-null and not empty, append ` \\\n  --data-raw '${_escapeBash(body)}'`.
         - Method `static String _escapeBash(String input)`: escape all single quotes `'` by replacing them with `'\''` (bash single-quote escape convention).
    2. Write `test/ui/curl_generator_test.dart`:
       - Test standard GET request generation with URL and headers.
       - Test POST request with JSON payload body.
       - Test single quotes / apostrophes in URL and body (e.g. `https://api.example.com/item's`, `{"message": "it's working"}`) and verify single quotes are correctly escaped as `'\''` ready for terminal execution.
       - Test that tracking headers starting with `:` are excluded.
  </action>

## STRIDE Threat Register

|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-07 | Denial of Service | ShareExporter / calculateAnchor | high | mitigate | Extract `RenderBox` bounds for `sharePositionOrigin` with fallback to screen center to prevent fatal `NSGenericException` popover crashes on iPadOS and macOS (D-64, UI-11). |
| T-04-08 | Information Disclosure | ShareExporter / ExportActionSheet | medium | mitigate | All exported records retain pre-persistence redaction (`[REDACTED]`), and an explicit "Exclude all headers" toggle allows developers to strip all request/response headers before sharing externally (D-63). |
| T-04-09 | Injection | CurlGenerator | low | mitigate | Escape single quotes as `'\''` and wrap arguments in single quotes to prevent shell parameter injection or terminal syntax errors when running generated cURL commands (D-61, UI-10). |
| T-04-SC | Tampering | pubspec dependencies | high | mitigate | Package legitimacy gate verified for all UI dependencies (04-RESEARCH.md). |
</threat_model>
