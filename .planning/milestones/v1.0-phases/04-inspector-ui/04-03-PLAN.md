<objective>
Build the multi-tab request inspection experience, zero-dependency formatted JSON viewer, and granular clipboard copy subsystem. Create `NetworkInspectorDetailScreen` featuring 4 main top-level tabs (Overview, Request, Response, Error) with header summary cards, query parameter breakdowns, multipart metadata, and stack trace rendering. Implement a zero-dependency Material 3 formatted JSON viewer (`JsonViewerWidget`) with syntax colorization, raw/pretty toggle, and background isolate parsing via `compute()` for bodies > 50KB to preserve 60fps responsiveness. Add granular clipboard copy buttons with confirmation SnackBars.

Purpose: Deliver deep diagnostic inspection into captured HTTP traffic with legible syntax formatting and one-tap clipboard extraction without third-party dependencies or main-thread UI frame drops.
Output: 4-tab details screen, background JSON formatting isolate utility, syntax-colored JSON viewer widget, copy button component, and comprehensive automated test suites.
</objective>

       - Top-level function `String formatJsonIsolate(String rawJson)`: attempt `jsonDecode(rawJson)`, format with `const JsonEncoder.withIndent('  ').convert(decoded)`, and return formatted string. Return original string on format error.
       - Function `Future<String> formatJsonBody(String rawJson)`: if `rawJson.length > 50 * 1024` (50KB), offload via `compute(formatJsonIsolate, rawJson)`; otherwise invoke synchronously.
    2. Create `lib/src/ui/components/json_viewer.dart` implementing `JsonViewerWidget` per UI-08, D-58, and `04-UI-SPEC.md`:
       - Accepts `final String? rawPayload; final BodyType bodyType; final bool isTruncated;`.
       - If `rawPayload == null || rawPayload.isEmpty`: display italicized subdued text "No payload body recorded" per `04-UI-SPEC.md`.
       - If `isTruncated`: render prominent warning banner "[Body truncated at 1MB]".
       - Header bar with title ("Payload Body"), byte size indicator, and "Raw / Pretty" toggle button (`SegmentedButton` or `IconButton`).
       - Formatted view: tokenize formatted JSON using pure Dart regex (`r'("([^"\\]|\\.)*")\s*:\s*|("[^"\\]*(\\.[^"\\]*)*")\s*(?!:)|(-?\d+(?:\.\d+)?(?:[eE][+-]?\d+)?)\s*|\b(true|false)\s*|\b(null)\s*'`) into styled `TextSpan` elements. Render inside `SelectableText.rich` with monospace font family (13px, 400, line height 1.4 per `04-UI-SPEC.md`).
