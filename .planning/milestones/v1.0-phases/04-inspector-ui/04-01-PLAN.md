<objective>
Establish the core Material 3 presentation scaffolding and listing feed for the network inspector. Lead with an end-to-end tracer slice connecting package dependencies (`share_plus`, `intl`), `NetworkInspectorConfig.navigatorKey`, and navigation deduplication guards on `NetworkInspector.open(context)` through to `NetworkInspectorScreen` rendering live `RequestTile` cards. Expand with threshold-based batch pagination (50 items/batch at 80% scroll depth), pull-to-refresh, local theme mode toggling (System / Light / Dark), and a clear-all confirmation dialog.

Purpose: Deliver the foundational browsing UI allowing developers to monitor HTTP traffic with status indicators, responsive scrolling, and database cleanup without blocking the UI thread or stacking duplicate routes.
Output: Core UI dependencies, navigator key configuration, navigation reentrancy guard, theme controller, view model, status/method badges, request card tile, clear-all dialog, listing screen, and automated widget tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host App → NetworkInspector.open | Host app initiates UI navigation; untrusted rapid calls or shakes cross here |
| SQLite Storage → UI Isolate | Persisted network records deserialized and loaded into widget memory |
| User Action → Storage Wipe | User triggers destructive repository clear-all action |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Elevation of Privilege | NetworkInspector.open | medium | mitigate | Track internal `_isOpen` reentrancy boolean and resolve root navigator (`rootNavigator: true`) with `navigatorKey` fallback to prevent navigation bypass or duplicate route stacking (D-51, D-52). |
| T-04-02 | Denial of Service | InspectorViewModel | medium | mitigate | Enforce strictly bounded batch pagination (`limit: 50, offset: offset`) at 80% scroll depth to prevent UI thread memory exhaustion during network bursts (D-56, UI-02). |
| T-04-SC | Tampering | pubspec dependencies | high | mitigate | Package legitimacy gate verified for `share_plus: ^13.3.1` and `intl: ^0.20.3` on pub.dev registry (04-RESEARCH.md). |
</threat_model>
