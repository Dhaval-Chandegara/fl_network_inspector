## Visual Hierarchy & Focal Points

### Main Listing Screen (`NetworkInspectorScreen`)
- **Primary Visual Anchor (Focal Point):** The method and status code badges on the newest `RequestTile` at the top of the feed (high-contrast colored badges draw the eye immediately to request status).
- **Secondary Anchor:** Persistent top `SearchBar` with debounced input and clear button.
- **Tertiary Anchor:** Horizontal `FilterChipsBar` providing immediate 1-tap filtering for common queries (All, Errors Only, 2xx, 4xx/5xx, POST, GET).
- **Accessibility:** All icon-only buttons (theme toggle, search clear, filter sheet trigger, sort menu, clear all) declare explicit semantic labels and tooltips (`tooltip: 'Switch Theme'`, `tooltip: 'Clear search query'`, `tooltip: 'Open filter sheet'`, `tooltip: 'Sort records'`, `tooltip: 'Clear all records'`).

### Details Inspection Screen (`NetworkInspectorDetailScreen`)
- **Primary Visual Anchor (Focal Point):** The Header Summary Card at the top of the Overview tab, highlighting HTTP Method, Status Code, Duration (ms), and Timestamp.
- **Secondary Anchor:** TabBar navigation bar (Overview, Request, Response, Error) with accent-colored active indicator.
- **Tertiary Anchor:** Dedicated granular copy buttons on each section with tooltip labels (`tooltip: 'Copy URL'`, `tooltip: 'Copy headers'`, `tooltip: 'Copy body'`).
- **Accessibility:** Copy buttons and share actions feature semantic tooltips and trigger lightweight confirmation snackbars.

## UI Considerations

Applicable state considerations resolved: 10 covered, 2 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Listing Screen (`list-collection`) | ✅ covered | When repository returns 0 records, renders documented empty state heading "No Captured Traffic" and guidance body copy with a network radar icon. |
| empty | Search / Filtered List (`list-collection`) | ✅ covered | When search query or filters match 0 records, renders "No Matching Requests" with a quick-action button to reset filters. |
| empty | Request / Response Body (`static-content`) | ✅ covered | When `requestBody` or `responseBody` is null or empty, displays italicized subdued label: "No payload body recorded". |
| empty | Error Tab (`static-content`) | ✅ covered | When request completed successfully without error, Error tab displays centered checkmark icon with text: "No errors encountered for this request". |
| loading | Listing Screen Initial (`list-collection`) | ✅ covered | Initial repository fetch displays centered `CircularProgressIndicator` until first batch of records resolves. |
| loading | Pagination / Infinite Scroll (`list-collection`) | ✅ covered | When scrolling within 20% of bottom, appends a subtle bottom loading indicator while fetching the next 50 records. |
| loading | Large JSON Payloads (`interactive-control`) | ✅ covered | Payloads > 50KB offloaded via `compute()` show an inline progress indicator before switching to formatted syntax view. |
| error | Database Fetch Failure (`list-collection`) | ✅ covered | If repository read throws an exception, displays error banner with documented copy "Failed to load network records: check storage permissions and tap Retry." and a "Retry" button. |
| populated | Listing Feed (`list-collection`) | ✅ covered | Two-line card tiles display method pill, status badge, truncated URL path, duration, timestamp, size, and status dot with 8px vertical padding. |
| partial | In-Flight / Pending Requests (`list-collection`) | ✅ covered | Requests with `NetworkStatus.pending` render a slate badge labelled "Pending", omitted duration, and pulsing indicator dot. |
| overflow | URL & Header Strings (`static-content`) | 🧪 backstop | Listing tile clips URL with ellipsis (`TextOverflow.ellipsis`). Detail screen uses horizontal scrolling or wrapping `SelectableText` to ensure zero overflow crashes. |
| long-text | Multi-megabyte bodies (`static-content`) | 🧪 backstop | Bodies capped at 1MB per Phase 1 `PayloadTruncator` display `[Body truncated at 1MB]` indicator; formatted syntax parser handles 1MB without UI crash. |
