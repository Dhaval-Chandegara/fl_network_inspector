<objective>
Implement the foundational transparent network capture engine for `dart:io` networking. Lead with a production-quality end-to-end tracer slice proving non-destructive response stream tapping (`StreamTransformer.fromHandlers`) and `dart:io` proxy wrapping through to repository persistence, followed by safe parent `HttpOverrides` chaining, Web-safe conditional platform exports, configurable host/URL blacklisting, binary stream memory bypass, and progressive SSE stream handling.

Purpose: Deliver transparent, crash-free HTTP capture for standard Dart/Flutter networking that never drains single-subscription response streams, never clobbers host application corporate proxies or custom SSL certificates, and isolates memory during large downloads.
Output: Production `StreamTapTransformer`, `InspectorHttpOverrides`, `InspectorHttpClient` wrappers, Web-safe platform bridge, and comprehensive automated test harness.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dart:io Client → Host Network Stack | Network requests cross into OS socket layer; sensitive auth credentials in headers must not leak into persistent storage |
| Network Stream → Memory Buffer | Untrusted remote response streams cross into local process memory; oversized or infinite streams must be bounded |
| Package → Host App HttpOverrides | Package hooks into global HttpOverrides; must not break host app corporate proxy or custom SSL validation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | `InspectorHttpClientRequest` / `Response` | high | mitigate | Run all captured headers, query params, and body strings through `RedactionEngine` before persisting to repository (D-09, D-10, D-12) |
| T-03-02 | Denial of Service | `createStreamTapTransformer` | high | mitigate | Enforce `maxBodyBytes` (default 1MB) limit in `BytesBuilder` accumulator; bypass binary streams completely (D-41, D-43) |
| T-03-03 | Elevation of Privilege | `InspectorHttpOverrides` | high | mitigate | Retain `HttpOverrides.current` and delegate client creation and proxy lookup to previous overrides (D-38); restore on dispose (D-40) |
| T-03-SC | Tampering | npm/pip/cargo/pub installs | high | mitigate | Package legitimacy gate verified in RESEARCH.md: only official SDK and verified pub.dev packages used |
</threat_model>
