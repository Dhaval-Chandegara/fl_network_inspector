<objective>
Implement dedicated client adapters for `Dio` (5.x) and `package:http` (1.x) with robust cross-interceptor deduplication. Ensure that requests instrumented via client adapters automatically suppress duplicate low-level `HttpOverrides` capture by injecting a synthetic tracking header (`x-network-inspector-id`) that is cleanly stripped before wire transmission, while extracting multipart metadata without raw binary byte storage.

Purpose: Enable developers using popular Dart HTTP clients (`Dio` and `package:http`) to obtain complete, non-destructive network visibility across mobile, desktop, and web with zero double-counting.
Output: `NetworkInspectorDioInterceptor`, `NetworkInspectorHttpClient`, wire header stripping in `InspectorHttpClientRequest`, and comprehensive unit/integration test suites.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Adapter → Wire Transmission | Synthetic tracking header crosses to external networks; must be stripped before wire dispatch |
| Dio Interceptor → SQLite Storage | Multipart uploads containing large files cross into inspection database; raw file bytes must be discarded |
| Duplicate Capture → Storage Bus | Simultaneous client adapter + HttpOverrides listeners could storm database with duplicate records |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Information Disclosure | `InspectorHttpClientRequest` | high | mitigate | Inspect headers for `x-network-inspector-id` and `x-fl-net-inspector-tracked-id` and remove before wire transmission (D-33) |
| T-03-05 | Denial of Service | `NetworkInspectorDioInterceptor` / `HttpOverrides` | high | mitigate | Mark request as suppressed in `InspectorHttpClientRequest` when tracking header is present, preventing duplicate database writes (D-33) |
| T-03-06 | Information Disclosure | `NetworkInspectorDioInterceptor` (FormData) | high | mitigate | Extract `MultipartEntry` metadata only (filename, length, content type); strictly discard raw binary byte streams (DATA-04) |
| T-03-SC | Tampering | npm/pip/cargo/pub installs | high | mitigate | Verified `dio` (5.11.1) and `http` (1.6.0) package legitimacy from official publishers on pub.dev |
</threat_model>
