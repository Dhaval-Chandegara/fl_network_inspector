<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer Application Code → Manual Logging API | Developer passes arbitrary Object? request/response bodies and stack traces into the inspector |
| Error Details → Persistent Storage | Detailed stack traces and error messages could expose internal server paths or auth tokens |
| Asynchronous Tracker Handle → Repository | In-flight tracker handles uncompleted by consumer code could accumulate memory if unbounded |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07 | Information Disclosure | `ManualLogger.logError` | high | mitigate | Sanitize error messages and run headers/bodies through `RedactionEngine` before repository persistence (D-09, D-47) |
| T-03-08 | Information Disclosure | `ManualLogger.logApi` (`Object? body`) | high | mitigate | Recursively redact sensitive fields in Map/List/JSON structures via `RedactionEngine` prior to storage (D-46) |
| T-03-09 | Denial of Service | `NetworkRequestTrackerImpl` | high | mitigate | Memory bounds via `PayloadTruncator` and FIFO repository pruning; `NoOpNetworkRequestTracker` returns zero-cost const instance when disabled (D-48) |
| T-03-SC | Tampering | npm/pip/cargo/pub installs | high | mitigate | Verified package provenance for all dependencies |
</threat_model>
