    - Provide static BodyType detect({String? body, String? contentType}):
      1. If body is null or empty, return BodyType.empty.
      2. If contentType contains "image/", "video/", "audio/", "application/octet-stream", "application/pdf", "application/zip", or body starts with binary summary prefix, return BodyType.binary.
      3. If contentType contains "application/json" or body trimmed starts with "{" and ends with "}" or starts with "[" and ends with "]", return BodyType.json.
      4. If contentType contains "application/x-www-form-urlencoded" or (body contains "=" and not "\n"), return BodyType.formData.
      5. If contentType contains "multipart/form-data", return BodyType.multipart.
      6. Otherwise return BodyType.text.

    Implement PayloadTruncator in lib/src/utils/payload_truncator.dart (per D-02, D-13, D-14):
    - Provide static PayloadData truncate({required String? body, required String? contentType, required int maxBytes}):
      1. If body is null or body.isEmpty, return PayloadData with null body, byteSize: 0, bodyType: BodyType.empty, isTruncated: false.
      2. If contentType is binary (e.g. image, video, audio, zip, octet-stream), create summary string "[Binary data: &lt;mime_type&gt;, &lt;size_bytes&gt; bytes]" (per D-14), measure summary bytes, and return PayloadData with bodyType: BodyType.binary and isTruncated: false.
      3. Encode body via utf8.encode(body) to measure exact original byte length.
      4. If original byte size &lt;= maxBytes, return PayloadData with body, byteSize: originalSize, bodyType: BodyTypeDetector.detect, isTruncated: false.
      5. If original byte size &gt; maxBytes, slice bytes via bytes.sublist(0, maxBytes). Safely decode sliced bytes with utf8.decode(slicedBytes, allowMalformed: true) to prevent FormatException crashes when slicing 2-4 byte UTF-8 sequences. Append banner "\n\n[Payload truncated at $maxBytes bytes]" (per D-13). Return PayloadData with truncated text plus banner, byteSize: originalSize, bodyType: BodyTypeDetector.detect, isTruncated: true.

    - Bodies below maxBytes (e.g. standard JSON) remain untruncated with isTruncated: false.
    - Oversized bodies exceeding maxBytes are truncated, contain the exact banner "\n\n[Payload truncated at X bytes]", and have isTruncated: true (D-13).
    - Multi-byte UTF-8 sequences (emojis, accented characters, international text) sliced mid-codepoint decode safely without FormatException crashes.
    - Binary content-types produce the metadata summary banner "[Binary data: &lt;mime_type&gt;, &lt;size_bytes&gt;]" rather than buffering raw binary strings in RAM (D-14).
