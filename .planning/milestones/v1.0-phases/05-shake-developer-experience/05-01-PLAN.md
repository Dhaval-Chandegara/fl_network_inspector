<objective>
Implement the core hardware shake detection engine and lifecycle-aware battery optimization manager. Build `ShakeDetector` subscribing to `userAccelerometerEventStream()`, calculating Euclidean motion vector magnitude, enforcing a 1500ms debounce cooldown, and pausing sensor sampling when the application is backgrounded (`paused`, `inactive`, `hidden`). Add configuration parameters `shakeThreshold` and `shakeDebounceMs` to `NetworkInspectorConfig`.

Purpose: Deliver accurate, battery-conscious physical device shake detection that isolates gravity and gracefully degrades when sensors are unavailable.
Output: Config updates, `ShakeDetector` controller, and automated test suite.
</objective>

  <action>
    1. Create `lib/src/shake/shake_detector.dart`:
       - Class `ShakeDetector with WidgetsBindingObserver`:
         - Fields: `final VoidCallback onShake`, `final double threshold`, `final int debounceMs`, `final Stream<UserAccelerometerEvent>? _customStream`.
         - State: `StreamSubscription<UserAccelerometerEvent>? _subscription`, `int _lastShakeTimestamp = 0`, `bool _isPaused = false`, `bool _isStarted = false`.
         - Method `void start()`:
           - Guard: if already started, return early.
           - Register `WidgetsBinding.instance.addObserver(this)`.
           - Resolve stream: `_customStream ?? userAccelerometerEventStream()`.
           - Subscribe with `onError: (e) { ... }` logging a single debug notice and cancelling subscription gracefully without crashing.
           - On event: calculate magnitude `math.sqrt(event.x * event.x + event.y * event.y + event.z * event.z)`.
           - If `magnitude >= threshold`:
             - Check `now - _lastShakeTimestamp >= debounceMs`.
             - If passed, update `_lastShakeTimestamp = now` and invoke `onShake()`.
         - Method `void pause()`: pauses `_subscription` if active.
         - Method `void resume()`: resumes `_subscription` if paused.
         - Method `void stop()`: cancels `_subscription`, removes lifecycle observer.
         - Override `void didChangeAppLifecycleState(AppLifecycleState state)`:
           - If `state == AppLifecycleState.resumed`: call `resume()`.
           - Else if `state == AppLifecycleState.paused || state == AppLifecycleState.inactive || state == AppLifecycleState.hidden`: call `pause()`.
         - Method `void dispose()`: calls `stop()`.
    2. Write `test/shake/shake_detector_test.dart`:
       - Test: Vector magnitude calculates Euclidean norm correctly.
       - Test: Events below threshold do not trigger `onShake`.
       - Test: Events at or above threshold trigger `onShake`.
       - Test: Rapid consecutive shake events within debounce window (1500ms) fire callback only once.
       - Test: Event arriving after debounce window fires callback again.
       - Test: Lifecycle state changes (paused/inactive) pause stream and prevent shake triggers.
       - Test: Lifecycle state change back to resumed restores shake triggering.
       - Test: Stream error is caught without unhandled exception.
  </action>
