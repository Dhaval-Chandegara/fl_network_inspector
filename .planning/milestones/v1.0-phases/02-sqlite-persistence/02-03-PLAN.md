## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI / Consumer Query → SQLite Driver | Filter and search query inputs crossing into SQL database query engine |
| Network Records → SQLite Storage | Raw network packets and sensitive credentials crossing into durable local SQLite database |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Injection | DatabaseQueryBuilder | high | mitigate | Build parameterized SQL queries using prepared statements and whereArgs array for all filter parameters (searchQuery, httpMethods, statusCodes, errorOnly, bounds) to eliminate SQL injection vulnerabilities. |
| T-02-06 | Information Disclosure | SqliteNetworkInspectorRepository | high | mitigate | Sensitive authorization headers, cookies, tokens, and credentials are deep-redacted via RedactionEngine before records are handed to repository.save() per DATA-06 to ensure plaintext secrets are never written to SQLite disk storage. |
| T-02-SC | Tampering | pub dependencies | high | mitigate | Package legitimacy audit verified on pub.dev for sqflite ^2.4.5, sqflite_common_ffi ^2.4.5, and path ^1.9.1. |
</threat_model>
