   - Name: `CI`
   - Triggers per D-13:
     ```yaml
     on:
       push:
         branches: [main]
       pull_request:
         branches: [main]
       workflow_dispatch:
     ```

     ```yaml
     concurrency:
       group: ${{ github.workflow }}-${{ github.ref }}

     ```

     ```yaml
     permissions:
       contents: read
     ```

     - Set up Flutter with `subosito/flutter-action@v2`, channel `stable`, and `cache: true` per D-15

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Pull Request / Push Event -> GitHub Actions CI Runner | Untrusted PR metadata, commit references, and workflow execution. |
| CI Workflow Jobs -> Branch Protection Gate | Upstream matrix job execution results feeding into aggregate branch status. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-03 | Elevation of Privilege | CI Workflow execution permissions in `.github/workflows/ci.yml` | high | mitigate | Configure workflow with read-only repository permissions (`contents: read`), avoid exposing secrets or publish tokens in pull requests, and enforce concurrency cancellation for outdated runs (`cancel-in-progress: ${{ github.ref != 'refs/heads/main' }}`) (per D-13, D-14). |
| T-13-04 | Repudiation | CI Matrix reporting and branch status verification | medium | mitigate | Implement aggregate status check job `all-checks-passed` with `if: always()` validating that all upstream jobs succeeded, preventing bypassed checks or silent matrix failures from green-lighting broken merges (per D-16). |
| T-13-SC | Tampering | Third-party GitHub Actions (`actions/checkout@v4`, `subosito/flutter-action@v2`) | high | mitigate | Pin official, verified action versions (`v4` and `v2`) audited in Package Legitimacy Audit; cache dependencies safely using `cache: true` (per D-15). |
</threat_model>
